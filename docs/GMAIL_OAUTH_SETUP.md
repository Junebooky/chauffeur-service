# Gmail OAuth setup (owner only)
- Google web OAuth client: localhost:5173/api/gmail/callback and production /api/gmail/callback. Only the configured GMAIL_ALLOWED_EMAIL can be connected. The existing SMTP reservation confirmation workflow remains unchanged.
- Local: run node scripts/setup-gmail.mjs "/path/to/downloaded-google-client.json" from repository root. Imports only Gmail variables into .env.local, retains other settings and the existing encryption key. Restart dev. Keep the downloaded JSON and .env.local out of Git.
- Production: five server env vars GOOGLE_OAUTH_CLIENT_ID, GOOGLE_OAUTH_CLIENT_SECRET, GOOGLE_OAUTH_REDIRECT_URI, GMAIL_TOKEN_ENCRYPTION_KEY (32-byte hex), GMAIL_ALLOWED_EMAIL. Do not deploy without explicit instruction. Local and production tokens are isolated by redirect URI and encryption key.
- Enable Gmail API; Google Auth Platform audience: add the allowed account as a test user if External/Testing. Approve gmail.readonly and gmail.send. Testing refresh tokens can expire in seven days. Review Google's restricted-scope verification requirements before wider use.
- Sign into /admin/live as owner, open Mail, connect the configured Google account, grant both scopes. OAuth uses PKCE, one-time DB state, HttpOnly SameSite cookie and server-side AES-GCM encryption. State expires after 10 minutes. No public email data or credential access.
- Create exact Gmail label CHAUFFEUR and apply it to business messages including general enquiries without booking numbers. Only labelled messages (excluding Spam/Trash) are loaded, on explicit refresh. Latest 20; plain text only, no HTML/attachments. Compose and explicit confirmation sends a new plain-text email. No automatic classification, reply threading, sent folder, pagination UI or automatic mail synchronization yet. No mailbox data sent to AI.
- Apply docs/sql/gmail-oauth-v1.sql in Chauffeur Supabase schema. Existing reservation tables unchanged. To disconnect, revoke the app in Google Account third-party access; reconnect in admin if necessary. Rotate exposed OAuth secrets and keep credentials server only.
