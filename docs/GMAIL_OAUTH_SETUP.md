- Google web OAuth client: http://localhost:5173/api/gmail/callback and https://www.jpchauffeurkorea.com/api/gmail/callback (legacy Vercel callback remains allowlisted during migration). Only the configured GMAIL_ALLOWED_EMAIL (company account topcs2026@gmail.com) can be connected. The owner login is separate. Live Supabase booking notifications and customer confirmations use the authorized company Gmail API (no SMTP password). Connect each environment once. The separate SQLite compatibility notifier still supports legacy SMTP.
- Local: run node scripts/setup-gmail.mjs "/path/to/downloaded-google-client.json" from repository root. Uses the existing .env (or .env.local if only that file exists), retains other settings and the existing encryption key, and refuses conflicting Gmail settings in .env.local. Restart dev. Keep the downloaded JSON and environment files out of Git.
- Production: five server env vars GOOGLE_OAUTH_CLIENT_ID, GOOGLE_OAUTH_CLIENT_SECRET, GOOGLE_OAUTH_REDIRECT_URI, GMAIL_TOKEN_ENCRYPTION_KEY (32-byte hex), GMAIL_ALLOWED_EMAIL. Do not deploy without explicit instruction. Local and production tokens are isolated by redirect URI and encryption key.
- Enable Gmail API; Google Auth Platform audience: add the allowed account as a test user if External/Testing. Approve gmail.readonly and gmail.send. Testing refresh tokens can expire in seven days. Review Google's restricted-scope verification requirements before wider use.
- Sign into /admin/live as owner, open Mail, connect the configured Google account, grant both scopes. OAuth uses PKCE, one-time DB state, HttpOnly SameSite cookie and server-side AES-GCM encryption. State expires after 10 minutes. No public email data or credential access.
- Company mailbox inbox and sent folder, optional exact CHAUFFEUR label filter, promotions/social review folder and pagination. Spam/Trash excluded. General enquiries need no booking reference. Plain-text display and confirmed new mail/threaded replies; attachments and rich HTML reading are not supported. No automatic classification or synchronization yet. No mailbox data sent to AI.
- Apply docs/sql/gmail-oauth-v1.sql in Chauffeur Supabase schema. Existing reservation tables unchanged. To disconnect, revoke the app in Google Account third-party access; reconnect in admin if necessary. Rotate exposed OAuth secrets and keep credentials server only.

- Automatic sender requires exactly one active owner connection for the configured mailbox and redirect. Mail recipients are saved customer email or company mailbox. HTML/CID/PDF MIME is sent through Gmail messages.send. Booking and confirmation queues are independent of delivery. Explicit failure is retryable in booking details; ambiguous delivery remains sending/uncertain and requires checking Sent before any resend. No automatic resend of historical records. Verify real account consent and controlled delivery before removing legacy SMTP vars.
