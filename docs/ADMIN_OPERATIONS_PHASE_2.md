# 운영 관리자 2차 작업
- 홈: 새 요청, 검토 중, 발송 확인 필요, 오늘·다가오는 확정 운행.
- 일정: 월간 캘린더, 날짜별 실제 예약, KST 기준. 취소/거절 제외. 미확정도 표시. 월별 실제 날짜 범위의 전체 일정 조회를 페이지 단위로 수행한다. 홈은 오늘부터 30일간의 확정 운행을 조회한다. 새 예약/메일 업무는 최근 150건 기준이며, 캘린더에서 더 오래된 예약도 상세 조회할 수 있다.
- 수정: 확정 전 고객 이름·이메일·전화번호 및 날짜별 날짜/시간/서비스/차종/출발지/목적지/항공편/금액/세금 조건을 수정. 경유지는 유지하며 변경된 주소는 관리자 입력값으로 저장하고 이전 장소 메타데이터를 비운다. 요금은 일별 합계로 재계산. 기존 날짜의 수 및 순서 유지, 겹치는 일정 거부. 날짜 추가/삭제, 경유지 수정 및 확정 이후 수정은 추후 버전 관리와 함께 구현.
- 운영 메모 및 최근 30건 처리 이력: 관리자 전용. 고객 PDF에는 포함되지 않는다.
- 운행 정보 복사: 고객 연락처/금액/내부 메모 제외. 관리자 확인 후 필요한 협력업체에 직접 공유.
- DB: docs/sql/booking-edit-v1.sql 추가. 서비스 역할 전용 RPC이며 기존 예약에 직접 변경을 가하지 않는다. SQL 테스트는 롤백.
- Gmail 수신함·OAuth, 확인서 수정 버전 발행, 리마인더는 아직 미구현. 실제 SMTP/관리자 브라우저 종단 검증은 별도 실시.
- Vercel 자동 배포 설정은 그대로 유지한다.

- 이메일 환경이 설정되지 않아도 예약 확정은 가능하다. 실패 상태를 표시하며 설정 후 재발송한다.
