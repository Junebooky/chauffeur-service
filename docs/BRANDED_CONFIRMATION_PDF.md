# Branded confirmation PDF
The A4 server renderer uses the same original server/assets/email-header-bg.jpg as the existing HTML email. Its first page uses the photo/brand banner, confirmed headline and reference, olive section headings, a three-column itinerary, a lower total and payment/guest instructions, and a light footer. Later pages use a compact continuation header. Text wraps by standard PDF font advances instead of counting characters. PDF remains selectable; Latin characters use Helvetica and other characters use the existing Korean CID font fallback (not full multilingual embedded fonts). A standard three-day booking is regression-tested as one page; longer schedules paginate. The stored PDF of an already issued confirmation is deliberately retained, and retries reuse it. New confirmations use the new layout. No automatic resend, DB mutation, or deployment.
